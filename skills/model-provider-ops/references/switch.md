# 額度警示與供應商切換

執行 `python3 scripts/quota_switch_guard.py --check --json` 取得狀態。查詢按觀察到的供應商與模型解讀；模型比例缺失便是未知，不能推為 0% 或 100%。

- 已知剩餘高於 10%：正常；已知 5–10%：提示剩餘量與重置時間；已知不高於 5%：提出備援建議。
- 不預設當前模型是 gpt-5.5；以實際設定和可用模型清單為準。不同产品／供應商額度不可混算。
- 已授權切換時，執行 `python3 scripts/quota_switch_guard.py --switch <openai|gemini|claude> --model <已核實模型>`。模型參數必填，避免舊預設靜默換型號。
- 切換會修改 Codex 設定、同步存在的 CC Switch 設定，並呼叫歷史修復。切換前先驗證目標 provider 定義、proxy 可連及指定模型可用；不要因低額度自行改服務。
- `--restart` 與 `--auto-guard` 需要既有明確授權；整理技能本身不授權模型切換、歷史清理或重啟。
- 腳本是按需執行，不能宣稱是常駐監控。持續監控僅在使用者要求時用 Codex automation，沿用既有排程以避免重複。

執行後重讀設定並檢查目標模型回應；只看到檔案寫入不能稱為切換成功。
